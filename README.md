### 小米 Mimo TTS 需要自己注册 key 限时免费, 使用方式有两种
> #### 1. 预设 | 就是预先训练好的音色类似微软的晓晓等,小米这边是冰糖茉莉

> #### 2. 自定义 可以通过文字自定义语调 比如下面这些, 发挥你的想象力,自行制作嗓音吧(推荐)
```bash

    - "元气少女": "活泼俏皮，语调上扬，充满朝气和感染力，像在和闺蜜分享开心的事",
    - "高冷御姐": "慵懒而从容，语调平稳不急不缓，带有淡淡的疏离感和自信",
    - "沉稳大叔": "醇厚低沉的嗓音，语速偏慢，沉稳有力，像深夜电台主播娓娓道来",

  ── 专业播报 ──────────────────────────────────────────────
```
